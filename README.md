Instalador portable para Windows 10/11 de 64 bits.

Al presionar el botón, comenzará la descarga de `PELAO-TWEAK-Setup.exe`.

Después de descargarlo:

1. Abre `PELAO-TWEAK-Setup.exe`.
2. Sigue las instrucciones del instalador.
3. Ejecuta PELAO TWEAK AMD desde el acceso directo creado.

## Requisitos

- Windows 10/11 de 64 bits.
- Ejecutar como administrador para aplicar algunos tweaks.
- Cerrar Fortnite antes de aplicar perfiles sobre `GameUserSettings.ini`.

## ¿Qué incluye?

- Dashboard de diagnóstico rápido.
- Perfiles para `GameUserSettings.ini`.
- Vista previa antes de aplicar cambios.
- Lista de procesos con protección para procesos críticos.
- Tweaks de FPS, ping, input lag, pantalla, energía, RAM y limpieza de logs.
- Backup automático al aplicar perfiles.

## Seguridad

La aplicación:

- No modifica archivos del juego como `.pak`, DLLs, Easy Anti-Cheat o BattlEye.
- No utiliza inyección, drivers, hooks ni bypasses.
- Se enfoca en configuraciones, procesos y scripts/tweaks incluidos.

## Uso recomendado

1. Descomprime el archivo `.zip`.
2. Ejecuta `AMD-Potato-Optimizer.exe`.
3. Utiliza primero la opción **Diagnóstico**.
4. En **Perfiles**, selecciona tu archivo `GameUserSettings.ini`.
5. Revisa la vista previa de los cambios.
6. Aplica el perfil.
7. En **Tweaks**, aplica únicamente las opciones que entiendas y necesites.

## Aviso

Algunos tweaks pueden modificar configuraciones de Windows y requerir permisos de administrador. Úsalos bajo tu responsabilidad.

Se recomienda crear un punto de restauración de Windows antes de aplicar cambios avanzados.
