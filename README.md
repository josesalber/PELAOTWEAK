# PELAO TWEAK AMD

Aplicacion portable para Windows enfocada en optimizaciones rapidas para Fortnite, procesos y tweaks del sistema.

## Descargar

Ve a la seccion **Releases** de este repositorio y descarga:

`AMD-Potato-Optimizer-portable.zip`

Luego:

1. Descomprime el ZIP completo.
2. Abre la carpeta descomprimida.
3. Ejecuta `AMD-Potato-Optimizer.exe`.

No muevas solo el `.exe`, porque la aplicacion necesita sus DLLs, assets, configuracion y archivos de tweaks incluidos en la carpeta.

## Requisitos

- Windows 10/11 x64.
- Ejecutar como administrador para aplicar algunos tweaks.
- Cerrar Fortnite antes de aplicar perfiles sobre `GameUserSettings.ini`.

## Que incluye

- Dashboard de diagnostico rapido.
- Perfiles para `GameUserSettings.ini`.
- Vista previa antes de aplicar cambios.
- Lista de procesos con proteccion para procesos criticos.
- Tweaks de FPS, ping, input lag, pantalla, energia, RAM y limpieza de logs.
- Backup automatico al aplicar perfiles.

## Seguridad

La aplicacion no modifica archivos del juego como `.pak`, DLLs, Easy Anti-Cheat o BattlEye.  
No usa inyeccion, drivers, hooks ni bypasses.  
Los cambios se enfocan en configuracion, procesos y scripts/tweaks incluidos.

## Uso recomendado

1. Descomprime el ZIP.
2. Ejecuta `AMD-Potato-Optimizer.exe`.
3. Usa primero **Diagnostico**.
4. En **Perfiles**, selecciona tu `GameUserSettings.ini`.
5. Revisa la vista previa.
6. Aplica el perfil.
7. En **Tweaks**, aplica solo las opciones que entiendas y necesites.

## Aviso

Algunos tweaks pueden modificar configuraciones de Windows y requerir permisos de administrador. Usalos bajo tu responsabilidad. Se recomienda crear un punto de restauracion de Windows antes de aplicar cambios avanzados.
